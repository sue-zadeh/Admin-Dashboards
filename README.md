# FormPilot | Interactive Contact Form Demo

Try three responsive layouts: **Studio Glass**, **Editorial**, and **Aurora**.

**[Open `index.html`](./index.html)** to preview the designs. The whole demo is contained in one HTML file, with no build or dependencies.

**Privacy:** This is only a visual demonstration. It does not send messages, collect contact information or connect to a database.

The complete commercial product is separate and private. It includes React + TypeScript source, a plain HTML/JavaScript edition, Node.js/Express API, PostgreSQL and an admin enquiries dashboard. The paid source is **not** in this public repository.

To host on GitHub Pages: Repository **Settings → Pages → Deploy from a branch → `formpilot-public-demo` / (root)**, then save. The Pages URL is not active until GitHub completes deployment.
